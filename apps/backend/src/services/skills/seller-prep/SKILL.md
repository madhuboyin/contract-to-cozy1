# Seller Prep Checklist Skill

## Purpose

Review the governed seller-prep checklist -- open repairs, records, and presentation work recommended before listing this home for sale.

## Select this Skill when

- Check my sale readiness
- Is my home ready to list yet?
- What's on my seller prep checklist?
- Am I ready to sell my house?

## Do not select this Skill when

- Guarantee this home will sell above asking price

## Operations
