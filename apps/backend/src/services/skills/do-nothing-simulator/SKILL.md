# Do-Nothing Simulator Skill

## Purpose

Review the latest Do-Nothing Simulator run: what putting off home upkeep could cost, the risk drivers, the biggest avoidable losses, the suggested next steps and the saved scenarios. Estimates, not predictions. Only the home's primary owner can see these runs.

## Select this Skill when

- Show my do-nothing simulation
- What is the cost of doing nothing on this house?
- What happens if we keep putting things off?

## Do not select this Skill when

- Run a new do-nothing simulation for 24 months
- The request is about one item's repair-or-replace timing (`repair-replace`)
- The request is about monthly ownership costs (`ownership-cost`)

## Operations

- `DO_NOTHING_SIMULATION`

## Consumers

- ASK: DO_NOTHING_SIMULATION

## Canonical ownership and boundaries

Operations remain owned by their registered canonical services and may be reached only through the adapters declared in the machine manifest. Context access is limited to declared providers. Peer Skill execution is prohibited; handoffs return to Ask for normal routing and authorization.
