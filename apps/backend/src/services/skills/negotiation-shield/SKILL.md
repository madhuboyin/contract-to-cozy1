# Negotiation Shield Skill

## Purpose

Review this home's Negotiation Shield cases: the quote, premium, claim, urgency and inspection negotiations prepared so far and where each one stands. Case descriptions, inputs, analyses and drafts stay on each case.

## Select this Skill when

- Show my negotiation shield cases
- List the negotiation reviews I have prepared
- Which of my negotiations have been analyzed?

## Do not select this Skill when

- Send my counteroffer to the contractor now
- The request is about a purchase negotiation with the seller or agent (`buyer-closing`)
- The request is to compare service quotes (`quote-comparison`)

## Operations

- `NEGOTIATION_SHIELD_CASES`

## Consumers

- ASK: NEGOTIATION_SHIELD_CASES

## Canonical ownership and boundaries

Operations remain owned by their registered canonical services and may be reached only through the adapters declared in the machine manifest. Context access is limited to declared providers. Peer Skill execution is prohibited; handoffs return to Ask for normal routing and authorization.
