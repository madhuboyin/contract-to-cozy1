# Property Tax Skill

## Purpose

Assess property-tax appeal readiness from recorded assessment, evidence, and deadline context.

## Select this Skill when

- Am I ready to appeal my property tax assessment?
- Show evidence for a property tax appeal
- Is my assessed value too high?
- Can I challange my property tax assessment appeal?

## Do not select this Skill when

- Guarantee that a tax authority will approve an appeal

## Operations

- `PROPERTY_TAX_APPEAL_READINESS`

## Consumers

- ASK: PROPERTY_TAX_APPEAL_READINESS
